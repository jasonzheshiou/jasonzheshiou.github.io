How it is measured.

Repository A references repository B when B’s slug — separators ignored — appears in any .py, .md, .toml, .txt, .yaml or .yml file of A under 1.5 MB. Self-references are ignored. No repository imports another at code level, which was checked separately: these are references, not dependencies. Measured 2026-10-19.

What this does not claim.

  • No repository imports code from another. A line between two discs means one names the other, not that it depends on it to run.
  • Some pairs refer to each other, so this is not a tree and cannot be drawn as one. A hierarchy would be tidier and wrong.
  • Disc area is monotone in the count, not proportional to it: the plate scales area as 8 + 5.5 √n. A disc twice the area is not twice the references.
  • M365-Copilot-Agent-Loop is public but has no local checkout on the machine that did the scan, so it is drawn and not measured.
  • data_transfer was scanned and is private, so it is not drawn. Nothing public refers to it, so nothing is hidden by leaving it out.
  • The bands — play, judgement, ground, instrument, decisions — are my claim about what each project is for. They are the one part of the drawing that is not measured.
  • Figures quoted on the cards carry their own studies, commits and denominators. This page adds no new measurement of anything except what refers to what.
